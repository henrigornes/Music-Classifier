# Music-Classifier
## Automix project for CS50P developped by Henri GORNES

**Abstract :**
The aim of this project is to find the best transitions for a DJ within a selection of tracks. This tool try and find the best similarity score based on the Key, the genre, the artist and the release date. For that, many ways to proceed are implemented.
